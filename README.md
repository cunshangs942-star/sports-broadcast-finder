# スポーツ中継どこで見れる？ - SPORTS ON AIR 2026

2026年シーズンの日本国内スポーツ中継・配信先を検索できるWebアプリです。

## 収録コンテンツ（2026年5月時点）

| スポーツ | リーグ・大会 |
|--------|------------|
| サッカー | Jリーグ、プレミアリーグ、ラ・リーガ、ブンデスリーガ、セリエA、リーグアン、W杯2026、日本代表、ACL |
| 野球 | プロ野球(NPB)、MLB、WBC |
| バスケ | Bリーグ、NBA |
| テニス | グランドスラム4大会、ATPツアー、WTAツアー |
| F1 | F1グランプリ（全24戦） |
| ラグビー | ジャパンラグビーリーグワン |
| NFL | スーパーボウル含む |
| ゴルフ | 4大メジャー、JLPGA、JGTO |
| その他 | 競泳、バレーボール |

## シーズン更新方法

`src/App.jsx` の冒頭にある `DB` オブジェクトを編集してGitHubにプッシュするだけで反映されます。

## ローカル開発

```bash
npm install
npm run dev
```

## Vercelへのデプロイ

1. GitHubにこのリポジトリをpush
2. [vercel.com](https://vercel.com) でGitHubアカウントでログイン
3. "New Project" → リポジトリを選択 → "Deploy"

Framework Preset: **Vite** を選択してください。
